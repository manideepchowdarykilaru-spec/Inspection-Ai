# Training dataset

Real shop-floor photographs of packaged commodities with hand-transcribed
declarations. This is what the recogniser is tuned and measured against.

```
dataset/
  images/          photographs (jpg/png) — not committed, keep your own copy
  labels.csv       ground truth, one row per photograph (committed)
  report.md        generated by npm run dataset:eval — per-field accuracy and every failure
  results.json     generated — machine-readable version of the report
  lines.jsonl      generated — every OCR line with the declaration it carries; feeds npm run nlp:train
```

## Workflow

1. Drop photographs into `dataset/images/`.
2. `npm run dataset:template` runs the pipeline over every image and writes
   `labels.template.csv` pre-filled with its guesses. Correct the guesses against
   the physical pack, clear anything not printed on the photographed panel, and
   save the result as `labels.csv` (append rows for new images; keep old rows).
3. `npm run dataset:eval` compares the pipeline against `labels.csv` and writes
   `report.md`. Read the failure list, fix the extractor or preprocessing, run again.
4. `npm run nlp:train` retrains the section classifier. It picks up
   `dataset/lines.jsonl` automatically, so the classifier learns the real OCR
   wording of these packs, not only synthetic templates.
5. With a cloud OCR key set, run the evaluation as `npx tsx --env-file=.env --tsconfig backend/tsconfig.json backend/scripts/dataset-eval.ts`. One run is 47 requests; the OCR.space free plan allows 180 per hour and 500 per day, and a 429 in the log means images silently fell back to the local engine and the score is not comparable.
6. `npm run extract:test` and `npm run ocr:bench` must still pass — they guard
   the cartons that were already working.

Matching rules: numbers (MRP, dates, licence) compare on digits only, so
`₹80.00`, `Rs.80/-` and `MRP 80` all agree. Text fields agree when one contains
the other or they share most words. A blank cell means "not printed on this
panel", and the pipeline is expected to return nothing for it.

## Label classes and where the declarations live

Observed across the 44 photographs of 10 September 2026 (baseline 224/564 field checks before this round, 251/564 after it with the local engine, 384/564 with OCR.space as the recogniser):

| Class | Examples | Declaration block | Typical reading problems |
|---|---|---|---|
| **Flexible pouch / wrapper** | Saffola oats, Unibic, Marie Light, Krackjack, chips, Cadbury wrappers | A stacked caption block `MRP ₹ / (incl. of all taxes) / USP / Lot No. / MFD / Use by` with inkjet or dot-matrix values printed beside or below it; net quantity printed separately in large type. Often the whole panel is rotated 90° or 180° in the photo. | Wrinkles, specular glare from the film, inkjet values mis-aligned with their captions, dot-matrix digits. |
| **Folding carton** | Ensure, Maharishi, Jersey, Priya, Tetley, Cadbury brownie, Sunfeast | Neat legal block (Mfd by / Mktd by / Lic. No. / consumer care) plus one inkjet row at the panel edge: `MFG 23/02/26 PKD 03/03/26 EXP 17/08/27 ₹515.00`, or a `Batch/Pkd/MRP/Use by` legend with values to the right. | Very small print, side panels photographed rotated, dot-matrix on coated board. |
| **Curved bottle (PET / glass)** | Thums Up, Bisleri, Bailley, Nyle, Meera, Dettol, Savlon, Hershey's, honey | Legal text wraps around the curve; MRP, batch and dates are frequently **not on the back label**: "for date of manufacture, expiry, batch no., USP & MRP see neck / cap / bottle". When present they are inkjet-coded on the shoulder or as a symbol legend (`# batch $ mfd ¥ exp`). | Curvature compresses text at the edges, white text on dark/transparent background, liquid refraction, glare. |
| **Tin / can / jar** | Milkmaid, Kimjo dates, Continental coffee | Body label carries manufacturer and net quantity; MRP and dates are dot-matrix on the lid or a sticker in a `MRP / USP / Date of Mfg / Use by / Batch` legend. | Reflective metal, ring-shaped text on lids, sticker over printed captions. |
| **Weigh-price / retail sticker** | Avni cashews, Premier napkins, Peace toilet paper | Single compact block: `ITEM: … Net Wt: … / Pkt Dt: … Exp Dt: … / MRP Rs.170/-`. Manufacturer usually elsewhere on the pack. | Printed under shrink wrap, low-contrast thermal print. |

Consequences for the recogniser:

- Orientation must be decided per photo (0°, 90°, 180°, 270° all occur).
- A legend caption with no value on the same line takes its value from the
  inkjet block printed beside or below the captions, in caption order.
- "See neck / see bottom / refer cap" means the declaration is genuinely absent
  from the panel; reporting nothing is correct and the officer should photograph
  the neck or lid as a second image.
- A revised MRP sticker or inkjet ("REVISED MRP ₹70") overrides the printed MRP.
